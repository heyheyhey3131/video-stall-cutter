# 卡顿静音裁剪器 V1.0

图形界面工具：剪掉「画面卡住」且「音量很小」的片段。画面和声音可以分开调节。

当前版本：**V1.0**

## 启动

双击 `启动裁剪器.bat`，或：

```bat
python app.py
```

需要：

- Python 3.10+（已装 `numpy`）
- `ffmpeg.exe`（会自动找 Format Factory / PATH；也可在界面里浏览指定）

## 用法

1. 选择输入视频，输出路径会自动填成 `原名_cut.mp4`
2. 用两根 **1–10 档滑条** 分别调画面和声音（左=严格，右=宽松）
3. 也可以直接改下面的数字：
   - 画面：冻结时长（秒）、噪声容差
   - 声音：音量阈值（dB）、最短静音（秒）
4. **分析预览** 只检测，不写新视频
5. **开始裁剪** 按当前条件导出

只有画面卡住 **并且** 音量低于阈值的重叠区间才会被剪掉。

## 档位大致含义

| 档位 | 画面 | 声音 |
| --- | --- | --- |
| 1 最严 | 约 0.25 秒定格就判卡顿 | 低于约 -30 dB 就算太轻 |
| 5 标准 | 约 0.60 秒 | 约 -42 dB |
| 6 适中 | 约 0.80 秒 | 约 -45 dB（接近上次实剪参数） |
| 10 最松 | 约 3 秒才算卡顿 | 低于约 -58 dB 才算太轻 |

滑条会改写数字框；手动改数字后档位显示为「自定义」。
